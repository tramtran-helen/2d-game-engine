# 2D Game Engine

A custom **2D game engine built in C++**, currently in progress, focused on learning and implementing core game engine architecture from scratch.

## Overview

This project explores the fundamentals of real-time engine development, including:
- **Entity Component System (ECS)** architecture
- **SDL2-based rendering and window management**
- **Fixed timestep game loop**
- **Lua scripting integration**

The goal is to better understand how modern game engines are structured at the systems level, with an emphasis on performance, modularity, and extensibility.

## Tech Stack

- **C++**
- **SDL2**
- **Lua**
- **Makefile**

## Current Features

- Game window creation and event polling
- Rendering pipeline setup
- Fixed timestep / delta time handling
- Logger implementation
- ECS design and partial ECS implementation
- Basic movement and render systems
- Lua scripting setup

## Purpose

This project is primarily a learning-focused systems project to deepen the understanding of:
- game loops and rendering
- memory-aware engine architecture
- component-based design in C++
- scripting integration in game development
